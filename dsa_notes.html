What is Stability?

🔒 Stable Sort — definition
A sorting algorithm is stable if, when two elements have the same value (key), their relative order is preserved after sorting. Whichever came first in the original array still comes first in the sorted output.
Real example: Sort students by grade. Two students both scored 85. A stable sort keeps them in their original relative order (e.g. alphabetical). An unstable sort can scramble them.

What is In-Place?

💾 In-Place — definition
An algorithm is in-place if it uses only O(1) auxiliary space — it rearranges elements within the original input using only a few extra variables. It does NOT need a separate buffer proportional to n.
✅ In-place (O(1) aux):
Bubble, Selection, Insertion, Heap, Quick Sort
Only need a temp variable + loop counters
❌ NOT in-place (O(n) aux):
Merge Sort — the merge step needs an auxiliary array of size n. You cannot merge two sorted halves without extra space.
Note: Quick Sort is "in-place" for data but uses O(log n) recursion stack. The stack is execution overhead, not a data buffer — so it's still called in-place.

1D Array

A 1D array is a single row of elements in contiguous memory. Every element is the same type with an index starting at 0. You can jump directly to any element using index arithmetic — no searching.

int arr[5] = {10,20,30,40,50} — 4 bytes each

10idx 00x1000
20idx 10x1004
30idx 20x1008
40idx 30x100C
50idx 40x1010
Address of arr[i] = base_address + i × element_size arr[3] = 0x1000 + 3×4 = 0x100C → O(1) single arithmetic step
Why O(1) access? The CPU computes the address arithmetically in one step. No loop, no search — just maths. This is the defining superpower of arrays and why they beat linked lists for random access.

3D Array

A 3D array = stack of 2D grids. Think floors of a building, each with a grid of rooms. Three indices: arr[depth][row][col].
Address of arr[d][r][c] = base + (d×R×C + r×C + c) × element_size For 2×2×3: arr[1][0][2] → offset = 1×6 + 0×3 + 2 = 8 elements from base
Uses: RGB images (height×width×3 channels) · Video (frames×height×width) · 3D games (x×y×z) · Scientific simulations (voxels)

Key algorithms

🔄 Reverse in-place — 3 pointer technique · O(n) time · O(1) space
Three pointers: prev=NULL, curr=HEAD, next. Each step: save next → reverse curr.next → advance both.
Before: 10→20→30→NULL (HEAD=10) Step 1: save next=20; 10.next=NULL; prev=10; curr=20 Step 2: save next=30; 20.next=10; prev=20; curr=30 Step 3: save next=NULL; 30.next=20; prev=30; curr=NULL After: 30→20→10→NULL (HEAD=prev=30) ✓
🐢🐇 Floyd's Algorithm — Cycle detect + Find middle · O(n) time · O(1) space
Slow moves 1 step, fast moves 2 steps.
Cycle: if they meet → cycle exists. If fast hits NULL → no cycle.
Middle: when fast hits NULL/NULL.next, slow is at the middle node.
📍 kth from end — Two pointer gap · O(n) time · O(1) space
Move ptr1 k steps ahead. Move both ptr1 and ptr2 together until ptr1 = NULL. ptr2 is now at the kth node from the end.

String basics

A string = sequence of characters stored in contiguous memory (like a 1D array of chars). In C: ends with '\0' null terminator. In Python / Java: strings are objects that store their length as metadata and are immutable (cannot be changed after creation).

"HELLO" in C-style memory (6 bytes)

'H'idx 072
'E'idx 169
'L'idx 276
'L'idx 376
'O'idx 479
'\0'idx 50

Red = null terminator (C only). Python/Java store length in the string object — no '\0' needed.

Immutable (Python, Java): Cannot be changed after creation. Every "edit" creates a new string. Loop concatenation is O(n²) — use join() or StringBuilder!
Mutable (C char[], C++ string): Can be modified in-place. Reversal, swaps work without extra memory.

Critical operations

📏 Length — O(1) Python/Java · O(n) C strlen
Python/Java store length as metadata → O(1). C's strlen scans character-by-character until '\0' → O(n). Classic exam trap!
🔗 Concatenation — O(n²) trap in loops
Each + on an immutable string allocates a new string and copies everything before it.
❌ BAD — O(n²): result = "" for w in words: result += w ✅ GOOD — O(n): result = "".join(words) # copy once
🪞 Palindrome — O(n) time · O(1) space
Two pointers from both ends moving inward. Compare arr[left] and arr[right]. If any mismatch → not palindrome. If pointers cross → palindrome.
"racecar": l=0,r=6: r==r ✓ → l=1,r=5: a==a ✓ → l=2,r=4: c==c ✓ → l=r=3: crossed → PALINDROME
🔀 Anagram check — O(n) time · O(1) space
Frequency count array of size 26 (lowercase). Increment for string1, decrement for string2. If all counts = 0 → anagrams. Space is O(1) because alphabet is a fixed constant (26).
🔍 KMP Pattern Search — O(n+m)
Precomputes a failure function (prefix table) in O(m). For each position in the pattern, stores the length of the longest proper prefix that is also a suffix. During search, when a mismatch occurs, use this table to skip redundant comparisons instead of restarting. Result: O(n) search, never re-examines text characters. Total: O(n+m) vs naive O(nm).

Key concepts

📦 Substring vs Subsequence
Substring = contiguous. "ell" ✅ in "hello".
Subsequence = ordered, can skip. "hlo" ✅ in "hello" (skip e, l).
All substrings are subsequences; not vice versa.
🌳 Trie (Prefix Tree)
Each root-to-node path = a prefix. Insert/search in O(L) where L = string length. Used in autocomplete, spell-check, IP routing.
